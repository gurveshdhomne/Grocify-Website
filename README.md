# 🛒 Grocify - Grocery Website

Grocify is a modern and responsive grocery shopping website built using **React.js** and **Tailwind CSS**.

The project provides a clean and user-friendly interface for browsing grocery products, exploring different categories, and viewing product information.

## ✨ Features

- 🏠 Modern Home Page
- 🥦 Grocery Categories
- 🍎 Fruits & Vegetables
- 🥛 Dairy & Eggs
- 🥩 Meat & Seafood
- 🛒 Product Cards
- ❤️ Wishlist/Favorite UI
- ➕ Add-to-cart UI
- ⭐ Customer Testimonials
- 🎁 Discount Banner
- 🚚 Delivery Process Section
- 📱 Fully Responsive Design
- 🧭 React Router Navigation
- 🎨 Modern UI using Tailwind CSS
- 📱 Mobile-friendly Navigation

## 🛠️ Technologies Used

## ⚙️ Installation & Setup

### 1. Clone the Repository

```bash
git clone https://github.com/gurveshdhomne/grocify-website.git
```

### 2. Navigate to the Project

```bash
cd grocify-website
```

### 3. Install Dependencies

```bash
npm install
```

### 4. Start the Development Server

```bash
npm run dev
```

The application will run on your local development server.

## 🧭 Pages & Navigation
